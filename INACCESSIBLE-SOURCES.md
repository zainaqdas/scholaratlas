### How to use this list

1. Start with **Section B** (network-temporary) — fetch the listed URLs from your own machine; most will open normally.
2. Then **Section A** — these need a non-headless browser or manual browsing; copy the scholarship listings into the format used by the existing importers (`data/uni_direct/records.jsonl` + `scripts/import-uni-direct.ts` for universities, or a new importer for aggregators).
3. **Section D** may render in a browser even though the HTML is empty.
4. **Section C** is not worth pursuing unless the domain is resurrected.
